  • @TextIndexed, @HashIndexed, @GeoSpatialIndexed

  • getCollection(), mongoTemplate
  • Constants: AppConstants.FIELD → resolved
  • DB names from properties, .env, Java config, URIs

📐 ESR Rule (Compound Index Ordering)

E — Equality
eq, in
S — Sort
ascending, desc
R — Range
gt, gte, lt, lte

❌ Bad: {createdAt:1, tenantId:1} (Range→Equality)
✅ Good: {tenantId:1, createdAt:1} (Equality→Range)

🗄️ Index Scanner — Features & Value

End-to-end MongoDB index lifecycle management

🔍 Scan & Analyze

  • Scan from Git or local path
  • Detects defined indexes + suggests missing ones
  • ESR-ordered compound suggestions
  • Database + collection on every result
  • Filter, search, select & create inline

⚡ Compare Live DB

  • Connect to MongoDB → fetch all indexes
  • Auto-match tenant-prefixed DBs
    candidates → abc_candidates, xyz_candidates
  • Show missing / covered / ESR violations
  • One-click create per index or bulk create all
  • Filters out default _id indexes

🔄 Script Compare

  • Compare tenant onboarding script vs code
  • Script from local file, Git repo, or paste
  • Shows gaps both ways:
    missing from script · extra in script
  • Reuse credentials from source selector

🚀 Multi-Tenant Create

  • Auto-detect DBs from code or pick from server
  • Select indexes → apply to N databases at once
  • Per-index result: created / exists / error
  • Works with {refNum}_dbName pattern

📦 Export & Integrate

  • Mongo Shell scripts with use db;
  • PyMongo scripts
  • Grouped by database → collection
  • Include suggestions toggle
  • Copy / Download ready

🎯 Why This Matters

  • No more missed indexes on new tenants
  • ESR compliance — faster queries
  • Single source of truth — code drives indexes
  • Multi-repo support — config + code + scripts
  • Self-service — devs & ops, no DBA needed
